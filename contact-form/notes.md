# Contact Form Page - Notes

## Project Overview
A modern, professional contact form page with a gradient background and clean white form container. The form collects user information and messages with proper validation.

## Key Features
- **Form Fields**: First name, last name, email, phone, subject dropdown, and message textarea
- **Form Validation**: Required fields marked with asterisks
- **Responsive Layout**: Two-column layout on desktop, single column on mobile
- **Additional Contact Info**: Email, phone, and address displayed below the form
- **Newsletter Subscription**: Optional checkbox for marketing
- **Gradient Background**: Modern purple gradient design

## HTML Elements Used
- Form elements: `<form>`, `<input>`, `<textarea>`, `<select>`, `<button>`
- Input types: text, email, tel (telephone), checkbox
- Labels with `for` attribute for accessibility
- Required attribute for form validation
- Semantic structure with proper form groups

## CSS Techniques
- CSS Grid for two-column form layout
- Linear gradients for background and button
- Flexbox for centering content
- Box shadows for depth
- Smooth transitions and hover effects
- Focus states for better UX
- Responsive design with media queries
- Color scheme: Purple gradient (#667eea to #764ba2)

## Form Fields
1. **First Name** (required, text)
2. **Last Name** (required, text)
3. **Email** (required, email validation)
4. **Phone** (optional, telephone format)
5. **Subject** (required, dropdown selection)
6. **Message** (required, multi-line textarea)
7. **Newsletter** (optional checkbox)
