# HTML Mini-Projects Collection

This repository contains 7 complete HTML projects, each demonstrating different web development concepts and design patterns.

## Projects Overview

### 1. Product Page (`product-page/`)
A professional e-commerce product page featuring:
- Product image (SVG placeholder)
- Product details with pricing and ratings
- Feature list with checkmarks
- Call-to-action buttons
- **Demo:** Open `product-page/index.html` in your browser

### 2. Contact Form (`contact-form/`)
A modern contact form with:
- Multi-field form with validation
- Two-column responsive layout
- Contact information display
- Newsletter subscription option
- **Demo:** Open `contact-form/index.html` in your browser

### 3. Landing Page (`landing-page/`)
A complete SaaS landing page including:
- Sticky navigation bar
- Hero section with CTAs
- Feature showcase grid
- Statistics section
- Comprehensive footer
- **Demo:** Open `landing-page/index.html` in your browser

### 4. Restaurant Menu (`restaurant-menu/`)
An elegant restaurant menu featuring:
- Multiple menu categories (Appetizers, Pasta, Mains, Desserts, Beverages)
- Dietary tags (Vegetarian, Gluten-Free, etc.)
- Prices and descriptions
- Chef's note section
- **Demo:** Open `restaurant-menu/index.html` in your browser

### 5. Blog Article (`blog-article/`)
A professional blog post page with:
- Article header with metadata
- Rich content (headings, lists, blockquotes, code blocks)
- Author bio section
- Related articles
- Share buttons
- **Demo:** Open `blog-article/index.html` in your browser

### 6. Pricing Page (`pricing-page/`)
A conversion-focused pricing page with:
- Three pricing tiers
- Feature comparison
- Featured "Most Popular" plan
- FAQ section
- Billing toggle (Monthly/Annual)
- **Demo:** Open `pricing-page/index.html` in your browser

### 7. Multipage Site (`multipage-site/`)
A complete 3-page website featuring:
- **Home page** (`index.html`) - Services showcase and company stats
- **About page** (`about.html`) - Company story, values, and team
- **Contact page** (`contact.html`) - Contact form and information
- Consistent navigation across all pages
- **Demo:** Open `multipage-site/index.html` in your browser

## How to Use

1. **View Locally:**
   - Simply open any `index.html` file in your web browser
   - For the multipage site, start with `multipage-site/index.html`

2. **Run with HTTP Server:**
   ```bash
   python3 -m http.server 8080
   # Then visit http://localhost:8080 in your browser
   ```

3. **Learn from Notes:**
   - Each project includes a `notes.md` file with:
     - Project overview and key features
     - HTML/CSS techniques used
     - Learning objectives
     - Possible enhancements
