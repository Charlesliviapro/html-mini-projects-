# Pricing Page - Notes

## Project Overview
A professional pricing page displaying three subscription tiers with features, a billing toggle, and an FAQ section. Designed to convert visitors into paying customers.

## Key Features
- **Three Pricing Tiers**: Starter, Professional (featured), and Enterprise
- **Billing Toggle**: Switch between monthly and annual billing (with discount badge)
- **Featured Plan**: Highlighted "most popular" plan with special styling
- **Feature Comparison**: Clear list of included/excluded features for each plan
- **FAQ Section**: Common questions and answers
- **Responsive Design**: Mobile-friendly card layout
- **Hover Effects**: Interactive elements for better UX

## HTML Structure
- Semantic sections for header, pricing cards, FAQ, and footer
- Grid layout for pricing cards
- Feature lists with visual indicators
- Toggle switch for billing options
- FAQ accordion-style layout

## CSS Techniques
- **CSS Grid**: Auto-fit responsive layout for pricing cards
- **Featured Card Styling**: Border and scale transform for emphasis
- **Gradient Background**: Soft gradient for page background
- **Hover Animations**: Transform and box-shadow transitions
- **Feature Icons**: CSS pseudo-elements for checkmarks/crosses
- **Badge Design**: Absolute positioning for featured badge
- **Button States**: Hover effects for CTAs
- **Color Palette**: Blue (#3498db), Green (#27ae60), Grey tones

## Pricing Tiers

### Starter ($9/month)

- 1 User

### Enterprise ($99/month)

- White Label

## Design Patterns
- **Anchoring Effect**: Three options help users choose the middle
- **Social Proof**: "Most Popular" badge on recommended plan
- **Feature Comparison**: Clear visual differentiation
- **Scarcity/Urgency**: Discount badge for annual billing
- **Trust Building**: FAQ section addresses concerns
- **Clear CTAs**: Prominent "Choose Plan" buttons
- **Value Proposition**: Features listed by importance

## Conversion Elements

2. Featured/recommended plan
3. Free trial mentioned
4. Discount for annual billing
5. Feature comparison
6. FAQ for objection handling
