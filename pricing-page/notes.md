# Pricing Page - Notes

## Overview
A professional pricing page for a SaaS product called "CloudFlow". Features three pricing tiers with a clean, modern design that helps guide users to the right plan.

## Features Implemented
- **Three Pricing Tiers**: Starter, Professional (featured), and Enterprise plans
- **Billing Toggle**: Monthly/Yearly option with savings badge (visual only)
- **Featured Plan**: Professional plan highlighted as "Most Popular"
- **Feature Comparison**: Check/cross icons for easy feature comparison
- **Clear CTAs**: Distinct call-to-action buttons for each plan
- **FAQ Section**: Answers common customer questions
- **Responsive Design**: Works on all screen sizes

## HTML Structure
- Semantic structure with header, main content sections, and footer
- Card-based layout for pricing tiers
- Lists for features
- FAQ accordion-style sections

## CSS Techniques
- CSS Grid for pricing card layout
- Flexbox for internal card elements
- Card hover effects for interactivity
- Featured card scaling and border highlight
- Badge positioning with absolute positioning
- Color-coded icons for features
- Box shadows for depth
- Responsive design with media queries

## Design Principles
- **Visual Hierarchy**: Featured plan stands out with border and scale
- **Scannability**: Easy to compare features across plans
- **Trust Building**: FAQ section addresses concerns
- **Clear Pricing**: Large, readable price points
- **Social Proof**: "Most Popular" badge influences decision-making

## Pricing Psychology
- **Anchoring**: Highest price makes middle option attractive
- **Highlighting**: Featured plan draws attention
- **Scarcity**: "Most Popular" creates FOMO
- **Value Communication**: Features listed clearly
- **Risk Reduction**: Free trial and money-back guarantee
