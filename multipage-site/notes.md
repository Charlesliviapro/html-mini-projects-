# Multipage Site - Notes

## Project Overview
A complete multi-page website for "TechCorp Solutions," a technology consulting company. The site includes three interconnected pages: Home, About, and Contact, with consistent navigation and styling.

## Site Structure

### Home Page (index.html)
- **Hero Section**: Eye-catching gradient header with dual CTAs
- **Services Grid**: 6 service offerings in a responsive grid
- **Stats Section**: Company metrics and achievements
- **Call-to-Action**: Conversion-focused section
- **Footer**: Comprehensive site links and contact info

### About Page (about.html)
- **Page Header**: Branded header with tagline
- **Our Story**: Company history and mission
- **Core Values**: 4 value cards highlighting company principles
- **Leadership Team**: Team member profiles with avatars
- **Consistent Navigation**: Same nav/footer as other pages

### Contact Page (contact.html)
- **Page Header**: Welcoming header
- **Contact Information**: Multiple ways to reach the company
- **Contact Form**: Functional form with validation
- **Map Section**: Placeholder for location map
- **Business Hours**: Operating hours display

## Key Features
- **Consistent Navigation**: Sticky navigation bar across all pages with active state indicators
- **Responsive Design**: Mobile-friendly layouts on all pages
- **Unified Styling**: Consistent color scheme, typography, and component design
- **Internal Linking**: Proper navigation between pages
- **Footer**: Identical footer on all pages with site-wide links
- **Semantic HTML**: Proper use of HTML5 semantic elements
- **Form Validation**: Required fields and proper input types

## HTML Elements Used
- Semantic tags: `<nav>`, `<header>`, `<section>`, `<footer>`, `<form>`
- Navigation with active state management
- Form elements with validation
- Grid and flexbox layouts
- Links for internal page navigation

## CSS Techniques
- **Sticky Navigation**: Position sticky for always-visible nav
- **CSS Grid**: For service cards, team members, and layouts
- **Flexbox**: For navigation and content alignment
- **Gradient Backgrounds**: Consistent purple gradient theme
- **Hover Effects**: Interactive states for links and cards
- **Active States**: Visual feedback for current page
- **Animations**: Fade-in animation on hero section
- **Responsive Design**: Media queries for mobile adaptation
- **Color Scheme**: Purple gradient (#667eea, #764ba2), dark blue (#2c3e50), light blue (#3498db)

## Navigation System
- Logo links to home page
- Three main navigation items: Home, About, Contact
- Active state styling shows current page
- Consistent across all pages
- Mobile-responsive navigation

## Design Consistency
