# Multipage Site - Notes

## Overview
A complete multipage website for a fictional technology company called "TechSolutions". Consists of three interconnected pages: Home, About, and Contact. Demonstrates proper navigation structure and consistent design across pages.

## Site Structure

### Home Page (home.html)
- **Hero Section**: Eye-catching gradient background with value proposition and CTA
- **Services Grid**: Six service cards showcasing company offerings
- **Statistics Section**: Four key metrics (clients, projects, experience, satisfaction)
- **Navigation**: Consistent navigation bar with active state highlighting

### About Page (about.html)
- **Page Header**: Branded header with company mission
- **Story Section**: Two-column layout with image and company history
- **Core Values**: Four value cards explaining company principles
- **Team Section**: Four team member profiles with roles and descriptions
- **Navigation**: Same navigation structure with About highlighted

### Contact Page (contact.html)
- **Page Header**: Inviting header encouraging communication
- **Two-Column Layout**: Contact information and contact form side by side
- **Contact Information**: Address, phone, email, and business hours
- **Contact Form**: Full form with name, email, phone, subject, and message
- **Map Section**: Placeholder for location map
- **Form Submission**: JavaScript handles form submission with confirmation

## Features Implemented
- **Consistent Navigation**: All pages share the same navigation bar with proper active states
- **Sticky Navigation**: Nav bar stays at top while scrolling
- **Responsive Design**: All pages adapt to mobile, tablet, and desktop screens
- **Visual Consistency**: Shared color scheme, typography, and design elements
- **Working Links**: All navigation links properly connect pages
- **Interactive Elements**: Hover effects, form validation, submission handling

## HTML Structure
- Semantic HTML5 throughout all pages
- Consistent header and footer across pages
- Proper navigation with active state classes
- Form elements with validation attributes
- Grid layouts for content organization

## CSS Techniques
- Shared styles across all pages (could be extracted to external CSS)
- CSS Grid for layouts
- Flexbox for navigation and cards
- Gradient backgrounds
- Box shadows for depth
- Transitions for smooth interactions
- Media queries for responsiveness
- Sticky positioning for navigation

## Design Patterns
- **Consistent Branding**: Logo, colors, and typography unified across all pages
- **Clear Visual Hierarchy**: Proper heading structure and spacing
- **Active State Indication**: Users know which page they're on
- **Footer Consistency**: Same footer on all pages
