# Restaurant Menu - Notes

## Overview
A professional restaurant menu for an Italian restaurant called "La Bella Cucina". Showcases a complete menu structure with appetizers, pasta, main courses, desserts, and beverages.

## Features Implemented
- **Multiple Menu Sections**: Organized by course type (Appetizers, Pasta, Mains, Desserts, Beverages)
- **Item Details**: Each dish includes name, description, and price
- **Special Badges**: Highlights chef's specials and house favorites
- **Dietary Information**: Icons and labels for vegetarian, spicy, dairy content
- **Restaurant Info**: Location, hours, and contact information in footer
- **Elegant Design**: Serif typography and warm color scheme for Italian ambiance

## HTML Structure
- Semantic sections for each menu category
- Consistent item structure with details and pricing
- Header with restaurant branding
- Footer with practical information

## CSS Techniques
- Flexbox layout for menu items
- Color-coded section headers
- Badge system for special items
- Gradient background in header
- Box shadows for depth
- Responsive design with media queries
- Typography choices to match restaurant theme

## Design Choices
- **Color Scheme**: Red (#c41e3a) for Italian theme, green for prices
- **Typography**: Serif fonts for elegance, sans-serif for descriptions
- **Layout**: Clean, easy-to-scan format
- **Visual Hierarchy**: Clear distinction between item names, descriptions, and prices
